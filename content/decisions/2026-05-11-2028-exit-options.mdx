# 2028 EXIT 4 옵션

**원칙:** 지금 결정하지 않는다. 2028까지 4 옵션 모두 살려둔다.

## 옵션 1. 완전 EXIT (100% 매각)
- 기준: 300~500억
- 조건: 전략적 인수자 등장 + 가족 라이프스타일 우선
- 결과: 즉시 싱가포르 이주, 비거주자 전환

## 옵션 2. 부분 EXIT (30~40%)
- 기준: 150~200억 + 경영권 유지
- 조건: PE/VC와의 파트너십 + 추가 성장 자본 필요
- 결과: 경영권 유지하며 자본·자유 확보

## 옵션 3. Series A
- 기준: 지분 15~20% 신주, 1,000억+ 평가
- 조건: 글로벌 VC 라인업 + 유니콘 트랙 진입
- 결과: 2030~2031 유니콘 Plan B 본격 가동

## 옵션 4. 자력 7층 (투자·매각 X)
- 조건: 자력 성장만으로 2030 도달 가능
- 결과: 외부 자본 없이 100% 컨트롤 유지

## 결정 트리거 (2028 상반기)

| 조건 | 우선 옵션 |
|---|---|
| 시장 호황 + 전략적 인수자 등장 | 1 |
| 시장 보통 + 추가 성장 여력 | 2, 3 |
| 시장 침체 | 4 (Plan B 진입) |

## 절대 원칙

1. 시한 흔들기 금지 (2028 상반기 6~9개월)
2. 38사 정면충돌 X, 베타 우회
3. EXIT 자체가 자산 — 결과 무관 시도
4. 자동화·위임 속도 우선, 죽어라 일하기 X
